# Internationalization (i18n) Guide

## Overview

SteadyLearn supports English (EN) and Spanish (ES) from Day 1.

**Strategy**:
- Database: Separate translation tables
- API: Accept-Language header for responses
- Errors: Language-agnostic codes, frontend translates
- Frontend: JSON translation files

## Database: Translation Tables

Each translatable entity has a corresponding `[Entity]Translation` table.

```
Course ←→ CourseTranslation (EN, ES rows)
Topic  ←→ TopicTranslation
Session ←→ SessionTranslation
```

### Schema Pattern

```
[Entity]Translation
├── Id: Guid (PK)
├── [Entity]Id: Guid (FK)
├── LanguageCode: string (en, es)
├── [translatable fields...]
└── Unique: ([Entity]Id, LanguageCode)
```

### Data Example

```
Courses:
  Id: 123
  IsPublished: false

CourseTranslations:
  Id: 1001, CourseId: 123, LanguageCode: en
  Title: "Introduction to Web Development"
  
  Id: 1002, CourseId: 123, LanguageCode: es
  Title: "Introducción al Desarrollo Web"
```

## API: Accept-Language Header

```
GET /api/courses/123
Accept-Language: es

→ Returns Spanish translation
```

### Header Values

```
Accept-Language: en          → English
Accept-Language: es          → Spanish
Accept-Language: es-MX       → Spanish (fallback)
Accept-Language: fr          → English (not supported)
```

### Middleware Implementation

```csharp
public class AcceptLanguageMiddleware
{
    public async Task InvokeAsync(HttpContext context)
    {
        var language = context.Request.Headers["Accept-Language"]
            .ToString()
            .Split(',')[0]
            .Split(';')[0]
            .Trim()
            .ToLower();

        context.Items["Language"] = language switch
        {
            "es" or "es-mx" or "es-ar" => "es",
            _ => "en"
        };

        await _next(context);
    }
}
```

## Backend Implementation

### Creating with Translations

```csharp
public async Task<Result<CreateCourseResponse>> Handle(CreateCourseCommand request, ...)
{
    var course = new Course
    {
        Id = Guid.NewGuid(),
        IsPublished = false,
        CreatedAtUtc = DateTime.UtcNow
    };

    var translations = new List<CourseTranslation>
    {
        new() { CourseId = course.Id, LanguageCode = "en", Title = request.TitleEn },
        new() { CourseId = course.Id, LanguageCode = "es", Title = request.TitleEs }
    };

    _db.Courses.Add(course);
    _db.CourseTranslations.AddRange(translations);
    await _db.SaveChangesAsync();

    return Result.Success(new CreateCourseResponse(course.Id));
}
```

### Querying with Language

```csharp
public async Task<Course?> GetCourseAsync(Guid id, string language)
{
    return await _db.Courses
        .Include(x => x.CourseTranslations
            .Where(t => t.LanguageCode == language))
        .FirstOrDefaultAsync(x => x.Id == id);
}
```

### In Endpoint

```csharp
var language = context.Items["Language"] as string ?? "en";
var course = await GetCourseAsync(courseId, language);
```

### Translation Hook

```typescript
export const useTranslate = () => {
  const [language, setLanguage] = useState<'en' | 'es'>('en');
  const [translations, setTranslations] = useState({});

  useEffect(() => {
    const lang = navigator.language.startsWith('es') ? 'es' : 'en';
    setLanguage(lang);
    import(`../locales/${lang}/auth.json`)
      .then(m => setTranslations(m.default));
  }, []);

  const t = (key: string) => 
    key.split('.').reduce((acc, part) => acc?.[part], translations) || key;

  return { language, t, setLanguage };
};
```
